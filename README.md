# ⚙️ Gear Clock

An elegant, steampunk-inspired analog clock built with **SVG** and **vanilla JavaScript**. Features brass gears, Roman numerals, a seconds sub-dial, and a date window — all rendered with rich gradients and shadows.

---

## 🖼️ Preview

A dark-themed chronometer-style clock with:
- Decorative brass gears in the background
- Roman numeral hour markers
- A seconds sub-dial at 6 o'clock
- A date window at 3 o'clock
- Three hands: brass hour, steel minute, rose-gold second

---

## 🚀 Quick Start

1. Download `clock.html`
2. Open it in any modern web browser
3. The clock starts automatically — no build step needed

```bash
# Or serve it locally
python -m http.server 8000
# Then visit http://localhost:8000/clock.html
```

## ⚙️ How It Works

### Hand Rotation

The clock hands are SVG `<g>` elements. They rotate using SVG's `transform` attribute (not CSS `transform`), which respects the group's local coordinate system:

```javascript
// Rotate around the clock center (300, 300)
hourGroup.setAttribute('transform', `translate(300,300) rotate(${hourDeg})`);
```

| Element | ID | Pivot Point |
|---------|-----|-------------|
| Hour hand | `#hour-hand-group` | Center of clock (300, 300) |
| Minute hand | `#min-hand-group` | Center of clock (300, 300) |
| Second hand | `#second-hand-group` | Center of clock (300, 300) |
| Sub-dial hand | `#sub-sec-hand` | Origin of its own group (0, 0) |

### Why `setAttribute` instead of `style.transform`?

SVG `transform` and CSS `transform` use **different coordinate systems**:
- `style.transform` rotates around the **top-left of the SVG viewport** ❌
- `setAttribute('transform', ...)` rotates around the **group's defined origin** ✅

### Angle Calculations

```javascript
const secDeg  = (seconds / 60) * 360;
const minDeg  = (minutes / 60) * 360 + (seconds / 60) * 6;
const hourDeg = ((hour % 12) / 12) * 360 + (minutes / 60) * 30;
```

## 🎨 Design Details

| Feature | Technique |
|---------|-----------|
| Brass look | SVG radial gradients (`#brass`, `#brass-dark`) |
| Steel minute hand | SVG linear gradient (`#steel`) |
| Depth & shadows | SVG `<filter>` with `feDropShadow` |
| Inner dial shadow | SVG `<filter>` with `feOffset` + `feGaussianBlur` |
| Gears | Reusable `<symbol id="gear">` instanced via `<use>` |
| Glass reflection | Semi-transparent ellipse overlay |

## 🛠️ Customization

### Change Colors
Edit the gradients in `<defs>`:

```xml
<radialGradient id="brass">
  <stop offset="0%" stop-color="#fde047"/>  <!-- highlight -->
  <stop offset="40%" stop-color="#d97706"/> <!-- midtone -->
  <stop offset="80%" stop-color="#92400e"/> <!-- shadow -->
  <stop offset="100%" stop-color="#451a03"/><!-- dark edge -->
</radialGradient>
```

### Resize the Clock
Change the `viewBox` and CSS width/height together:

```css
.clock { width: 400px; height: 400px; }
```

```xml
<svg viewBox="0 0 400 400">
  <!-- also update all cx="300" cy="300" to cx="200" cy="200" -->
</svg>
```

### Add More Gears
Duplicate the `<use>` elements and adjust position/opacity:

```xml
<use href="#gear" x="200" y="200" width="80" height="80" opacity="0.3"/>
```
